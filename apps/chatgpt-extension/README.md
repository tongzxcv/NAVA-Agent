# NAVA Command Room Wake Extension

Manifest V3 browser extension slice for NAVA Phase 3D. It pairs one ChatGPT
conversation with the existing loopback Command Room Extension Bridge and
shows recoverable wake events in that exact tab.

## What this slice does

- accepts only the JSON pairing payload generated by NAVA Desktop;
- accepts only `http://127.0.0.1:18766` as the Bridge endpoint;
- binds to the exact ChatGPT conversation path (`/c/<id>` or
  `/g/<gpt>/c/<id>`);
- refuses missing or duplicate matching tabs;
- refuses an unsupported page, an ambiguous composer, a non-empty composer, or
  an active generation state;
- calls only the existing pair, wake-list, wake-transition, and touch Bridge
  routes;
- displays a visible wake banner and lets the user copy a fixed continuation
  prompt manually.

The extension never reads cookies, transcripts, API keys, files, shells, or
generic MCP tools. It never overwrites or submits the ChatGPT composer.

## Build and load unpacked

From the repository root:

```powershell
corepack pnpm@10.15.0 --filter @lnwjud/chatgpt-extension typecheck
corepack pnpm@10.15.0 --filter @lnwjud/chatgpt-extension test
corepack pnpm@10.15.0 --filter @lnwjud/chatgpt-extension build
```

In Chrome, open `chrome://extensions`, enable Developer mode, choose **Load
unpacked**, and select the generated `apps/chatgpt-extension/dist` directory.
Open the extension popup once and use **Copy Extension Origin**. Add that
exact `chrome-extension://...` origin to NAVA's explicit Extension Bridge
allowlist, enable Extension Wake, and restart/refresh the Bridge if NAVA asks.

Then open the intended ChatGPT conversation, create a Pair payload in NAVA's
Command Room controls, paste it into the popup, and choose **จับคู่แท็บนี้**.
Use **ตรวจ wake ที่รออยู่** to deliver pending wake banners.

## Deliberate Phase 3D slice boundary

The bearer token is held only in `chrome.storage.session`; the installation
identity alone is kept in `chrome.storage.local`. A browser restart therefore
requires pairing again. Persistent encrypted browser material, automatic
polling, SPA router instrumentation, and an explicit user-submit flow remain
later acceptance gates. No installed NAVA runtime is changed by this package.
